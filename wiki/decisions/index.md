# Decision Records

Architecture and compromise decisions for the YouTube video plugin, one record per decision, numbered chronologically.

## Records

* [Additive v2 API expansion with construction-time rebuild discipline](0001-additive-v2-api-expansion.md) - Inherited from the GCore upstream (historical). Additive-only ACE expansion, construction-time rebuild discipline, and empirical verification mandate for the GCore v2 API conversion. Its "(issue #1)" refers to the upstream GCore repo, not this fork's issue #1 (the YouTube port epic).
* [playerVars mapping constraints for issue #3](0002-playervars-mapping-constraints.md) - playerVars wiring constraints from issue #3: mute ownership deferred to #4, append-only positional property contract (idx5/idx6 for loop/start; renumber in #7), origin scheme guard, modestbranding omitted, loop/start build-time-only.
* [Mute state (`audioState`) is authoritative from the DOM side, decoupled from reported volume](0003-mute-state-decoupled-from-volume.md) - Mute state (audioState) is authoritative from the DOM seam (YT.Player.isMuted()), decoupled from reported volume; establishes the pattern for all future player-derived state (issue #4, epic #1).
* [Retire quality ACE surface (pre-release removal policy)](0004-retire-pre-release-quality-aces.md) - Pre-release ACE removal policy; retires SetQuality, GetCurrentQuality, GetQualityCount (issue #5, epic #1). Supersedes ADR-0001 section 1 for the pre-release window.
* [Awaitable Load Video — polled `getDuration()` readiness signal](0005-awaitable-load-video.md) - Load Video made awaitable via polled getDuration() > 0; explains why GCore's resolve-at-Ready doesn't port and why PLAYING is unreliable; settle-on-all-outcomes semantics, generation counter, 15s timeout (issue #18).
* [Video URL Parsing Scope — Parse-Only, Defer Playlist Load/Nav](0006-video-url-parsing-scope.md) - extractVideoId() scoped to parse-only: locks the guaranteed single-video URL set (adds /live/), documents the host-agnostic guarantee (nocookie/mobile/music subdomains) and the ignored list=/t=/si=/index= params; playlist load/navigation deferred to issue #12 (issue #8).
* [Captions: Map On/Off + Preferred Language, Retire the Rest](0007-captions-map-retire-subtitle-aces.md) - Captions: keep and enrich video-subtitles/SetSubtitles/Subtitles (wires cc_lang_pref alongside cc_load_policy, both build-time only); retire the 9 GCore-era side-loaded/enumeration ACEs with no YouTube equivalent; live switching via the unofficial captions module deferred to a future issue (issue #6, epic #1).
* [Playback-rate and video-metadata ACEs](0008-playback-rate-and-metadata-aces.md) - Playback rate (pass-through SetPlaybackRate, authoritative GetPlaybackRate, indexed GetAvailablePlaybackRate/Count) and metadata (GetVideoTitle via unofficial getVideoData(), GetPlayerUrl, polled GetVideoLoadedFraction) ACEs; playlist load/navigation split out and deferred to a follow-up issue (issue #12, epic #1).
* [Gate docs/usage.md drift against the ACE surface](0009-gate-docs-drift-against-ace-surface.md) - scripts/validate-docs.mjs gates usage.md only (README/TOC carry no checkable ACE content) via section-8-table + backticked-PascalCase resolution against the ACE surface (Check A), plus an en-US.json-desc-vs-plugin.ts-default regression guard (Check B) so the enable-chrome class of drift (issue #30, PR #33) can't recur silently; closes issue #31.
